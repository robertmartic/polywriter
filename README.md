# PolyWriter

[Download PolyWriter for Windows](https://github.com/robertmartic/polywriter/releases/latest).
Choose the `-setup.exe` asset for a conventional installation, or the `-win-x64.zip` portable package.

Version 0.1.0. A local document workspace for 64-bit Windows 10 (2004+) and Windows 11.
Free to use. English interface, light and dark themes, no account or subscription.

Create and format everyday documents, find text, preview pages and print.
Documents use the versioned .polyw format. TXT and basic RTF can be imported;
imports are copies and their originals are preserved. Export TXT or RTF from View.
Paste inserts plain text. DOCX is not supported in this version. Editing is continuous;
Print preview is paginated. Choose View > Write to leave preview.

Use Layout > Page setup for paper and margins. For PDF output choose Print,
then Microsoft Print to PDF if installed. This is not a built-in PDF export engine.

Unsaved work is checkpointed locally every 15 seconds and encrypted for your
Windows account. After an interrupted session, recovery is offered as a new
unsaved document. Recovery is best effort and does not replace saving files.

Keyboard: Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S, Ctrl+P, Ctrl+F,
Ctrl+Z/Y, Ctrl+B/I/U, Ctrl+X/C/V. Open another application window for another document.

See docs/INSTALLATION.md and docs/UPDATES.md. Licenses are included in the package.
