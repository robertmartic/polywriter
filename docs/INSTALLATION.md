# Installing PolyWriter

Use PolyWriter-0.1.0-setup.exe for a per-user installation, optional desktop and
Start menu shortcuts, Open with registration for .polyw and a conventional uninstaller.
No administrator rights or separate .NET installation are required.
Close all PolyWriter windows before installing. Existing folders and shortcut
choices are preserved on reinstall; setup rejects downgrades.

The default folder is %LOCALAPPDATA%/Programs/PolyWriter. Settings, encrypted
recovery and updates are separate in %LOCALAPPDATA%/PolyWriter. PolyPDF is independent.
Uninstall preserves documents and preferences. Setup never changes default file associations.

For portable use extract the entire PolyWriter folder from the win-x64 ZIP.
Portable copies can check for updates but require installation for in-app replacement.
